## 👨‍💻 About

<img align="right" width="360" alt="coding" src="https://user-images.githubusercontent.com/74038190/225813708-98b745f2-7d22-48cf-9150-083f1b00d6c9.gif" />

I'm a software engineer at **Big Circle**, working across production client products. I build the parts that have to be right: payment rails, multi-tenant platforms, concurrency-safe data models, and retrieval systems whose answers you can actually trust. **Backend depth first, applied AI on top.**

> The method is always the same — **find how it breaks first, make the failure visible, then build.**

- 🧱 &nbsp; **Backend & platform** — IBAN payouts over OAuth2 + mTLS with idempotent webhooks, per-contract Postgres advisory-lock protocols, a data-model migration across 238 files, six BullMQ/Redis queues with SSE progress.
- 🔎 &nbsp; **Production RAG** — hybrid retrieval (BM25 + pgvector, RRF), cross-encoder reranking, Docling ingestion, LangGraph agents, and evaluation gated in CI with RAGAS and DeepEval.
- 🌱 &nbsp; **Building** — *citecheck*, a reference checker that flags fabricated, retracted and misquoted citations in academic writing.
